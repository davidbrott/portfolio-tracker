# Portfolio Tracker

A full-stack portfolio tracking application built with **Spring Boot** and **Angular 22**.

The project is designed as a learning and reference project for exploring modern software engineering practices and building a maintainable, production-oriented application.

## Features

- Manage accounts, assets, and transactions
- RESTful backend API
- Modern Angular frontend

## Project Structure

```text
portfolio-tracker/
├── backend/     # Spring Boot
└── frontend/    # Angular 22
```

## Tech Stack

- **Backend:** Java, Spring Boot, Spring Data JPA
- **Frontend:** Angular 22, TypeScript, SCSS
- **Database:** SQLite

The project evolves continuously as new technologies, patterns, and best practices are explored.
